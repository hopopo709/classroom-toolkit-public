# 교실 도구함 — 공개 코드

교실 타이머, PDF 글자 수 세기, 개인정보 점검·비식별화 도구의 로컬 브라우저용 웹앱입니다. `index.html`을 직접 열어 사용합니다. 일기장 및 일기 API·데이터는 공개 저장소에 포함하지 않습니다.

개인정보 탐지 누락 가능성이 있으므로 실사용 학생 자료를 자동 비식별화한 결과는 반드시 사람이 확인하세요. 일부 PDF·엑셀 형식에서 보존되지 않는 정보가 있으며, 서비스 보안 인증을 받은 제품이 아닙니다. GitHub 코드 공개는 웹 배포와 별개입니다.

민감 자료(.env, 원본 문서, DB, 로그, 백업)는 절대 커밋하지 마세요.
